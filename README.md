# KROMATIC community levels

Catalog of player-made levels for the game **KROMATIC**. The game reads `levels/index.json` and `levels/<id>.json`
from this repository (read-only, no accounts required to play).

## Publish your level
1. In the level editor open **LEVEL MENU → PUBLISH LEVEL**, choose a nickname (**not your real name**).
2. Press **1. COPY CODE**, then **2. OPEN GITHUB FORM**, paste the code and submit the issue (a GitHub account is required).
3. A maintainer reviews the level. Approved levels are added automatically and appear in the game within a few minutes.

A level must contain exactly one player and at least one goal.

## Rules
- Only publish levels you made yourself and that contain no third-party copyrighted material.
- No offensive, hateful, illegal or personal content in level names, nicknames or issues.
- Everything you submit is **public** (nickname, level name, level data) and stays public in the repository history.

## License
By submitting a level you dedicate it to the public domain under **[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)**.

## Privacy
This repository is hosted on GitHub. The game downloads the level list from `raw.githubusercontent.com`; GitHub can therefore
see the IP address of the player's device. The game itself does not send any data to the developers and has no user accounts.
Submitting a level creates a public GitHub issue under your GitHub account, which is governed by GitHub's own terms and privacy statement.

## Report / remove a level
Use the **REPORT** button in the game or open an issue with the "Report a level" form (this also works for illegal content,
copyright infringement or personal data). Reported levels are reviewed promptly and removed from the catalog if they violate the rules.
